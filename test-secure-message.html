🔐 SKRAM Secure Message Authentication System

This system provides enterprise-grade secure messaging with HIPAA-compliant audit logging.

📋 System Features

  • Secure Message Authentication: Password-protected messages requiring user's system password
  • PHI (Protected Health Information) Detection: Automatic detection and special handling of healthcare data
  • HIPAA Compliance Logging: Complete audit trails for all PHI access attempts
  • Multi-Level Security: Confidential, Restricted, and Classified message levels
  • Real-time Authentication: Immediate password verification with encrypted content decryption
  • Attachment Security: Secure viewing of file attachments after authentication

🚀 How It Works

  1. Message Creation: Users can create secure messages with PHI content detection
  2. Security Classification: Messages are automatically classified by security level
  3. Authentication Required: Secure messages display as encrypted yellow boxes
  4. Password Challenge: Users must enter their system password to view content
  5. Audit Logging: All access attempts are logged for compliance (success and failures)
  6. Content Decryption: Successful authentication reveals message content and attachments

📊 HIPAA Compliance Features

  • PHI Type Categorization: Insurance cards, patient names, DOB, SSN, medical records, diagnoses
  • Access Logging: User ID, email, workforce affiliation, IP address, timestamp
  • Authentication Results: Success/failure tracking with detailed audit trails
  • Session Tracking: Links access attempts to user sessions for forensic analysis
  • Workforce Isolation: Cross-workforce security boundaries maintained

🎯 User Interface Integration

The secure message system is integrated across all three user interfaces:

  • Regular Users (Home.tsx): Can view and authenticate secure messages in their conversations
  • Moderators (ModeratorDemo.tsx): Full access to secure messaging with team management capabilities
  • Master Admins: System-wide secure message oversight and audit log access
