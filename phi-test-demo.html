Live PHI Detection Integration

1
User types message in any of the three chat interfaces (Regular User, Moderator, Master Admin)
2
User clicks Send button - PHI detection modal automatically appears
3
User reviews message content and indicates if it contains healthcare information
4
If PHI detected: User selects types, sets password, chooses security level
5
System automatically converts to secure message with password protection
